# Docsify 数学公式与内容对齐设计

## 目标

让 Docsify 网站以与 Typora 一致的方式渲染 LaTeX 数学公式，并使行外公式和正文图片居中；行内公式保持在普通文本流中。

## 方案

在 `docs/index.html` 中加载 KaTeX、`marked@4` 与 `docsify-katex`。插件将 Markdown 中的 `$...$` 渲染为行内公式，将 `$$...$$` 渲染为行外公式。

新增 `docs/custom.css` 并在入口页引用：

- `.markdown-section img` 使用块级布局、最大宽度为容器宽度，并使用左右自动外边距居中；
- `.katex-display` 使用块级布局并居中；
- 不对 `.katex`（行内公式）设置块级或居中样式。

## 验收标准

- `$s_1$` 显示为行内下标公式；
- `$$...$$` 显示为居中的独立公式；
- 第 2 课中的三张图片居中且不会超出正文宽度；
- 页面无 JavaScript 控制台错误，图片与公式均可在本地预览中加载。
